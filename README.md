# FRe:Q. Official Website

FRe:Q.（フリーク）の独立アーティスト公式サイト。GitHub Pages対応の静的HTML/CSS/JavaScript。

## 更新

公開情報・写真・作品・公演・映像・連絡先はcontent.jsで編集。編集後に `node scripts/build.mjs` で7つのHTMLを出力します。追加依存なし。

集合写真はheroImage、個人写真はmembers[].image。未確定の過去曲・公演・SNS・連絡先は創作していません。Midnight callingは仮設定と表示。公開JSには内部設定・機密情報を置かないでください。

## 公開

GitHub Pagesのmainブランチ・ルートで配信。OGPはassets/ogp.png。
